# E-Commerce Customer Intelligence

An end-to-end data analytics project focused on understanding customer behavior, retention, segmentation, and customer value.

The project transforms raw e-commerce customer and order data into useful business insights and customer segments.

## Project Workflow

* Data loading and cleaning
* Exploratory data analysis
* SQL analysis
* Customer-level feature engineering
* RFM segmentation
* Cohort retention analysis
* K-Means customer clustering
* Tableau dashboard

## Tools

Python, Pandas, NumPy, SQL, PostgreSQL, Docker, Scikit-learn, Plotly, Tableau

## Project Structure

* `notebooks/` – data cleaning, analysis, segmentation, retention, and clustering
* `sql/` – SQL queries and database analysis
* `templates/` – reusable visualization functions
* `dashboard/` – Tableau dashboard and related files
* `docker-compose.yml` – PostgreSQL database setup

## Outcome

The project provides insights into customer purchasing behavior, revenue, retention, and customer segments to support data-driven marketing and retention decisions.
